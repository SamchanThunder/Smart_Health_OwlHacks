# CareCompare 💊

**OwlHacks 2024 — Winner, Smart Health Track (Temple University)**

CareCompare helps patients find the most affordable medication options by integrating the Mark Cuban Cost Plus Drugs API for real-time medication price search and comparison.

## 🔗 Live Demo
[CareCompare](https://samchanthunder.github.io/Smart_Health_OwlHacks/)

## 🛠️ Built With
- JavaScript
- HTML
- CSS
- [Mark Cuban Cost Plus Drugs API](https://us-central1-costplusdrugs-publicapi.cloudfunctions.net/main)

## 💡 Motivation
We realize that innovation comes not only in the form of creating something new, but can also be in the form of making existing resources more accessible to all. Many sick individuals think not of their health as the main priority but of the price tag that comes along with improving their health. Realizing that the healthcare industry has strayed towards being more about profit margins as opposed to the health of customers, we decided to create CareCompare to find the most affordable options to medication.
